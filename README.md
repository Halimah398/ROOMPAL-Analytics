# ROOMPAL-Analytics
This project presents a structured data analysis of responses collected from the Apartment, House-Sharing, and Roommate Experience Survey (Nigeria). The primary purpose of the study is to transform raw survey responses into meaningful insights that describe respondents’ demographic characteristics, current living situations, housing experiences, and interactions with shared housing and digital housing platforms.
